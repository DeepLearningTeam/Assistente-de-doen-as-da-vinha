# Dados

- `docs/`: PDFs locais, ignorados pelo Git. Não redistribuir os PDFs.
- `images/`: imagens FieldVitis locais, ignoradas pelo Git; confirmar condições da licença no repositório original.
- `corpus.csv`: metadados versionados dos documentos, sem o conteúdo integral dos PDFs.
- `splits.json`: registo das divisões das imagens, depois de criadas a partir dos ficheiros reais.
- `perguntas/perguntas.csv`: conjunto de avaliação e passagens de referência.

Apenas indicar uma licença em `corpus.csv` depois de a verificar na fonte original. “Disponível publicamente” não significa automaticamente “licença aberta”.
